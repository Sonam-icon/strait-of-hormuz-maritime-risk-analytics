# Project Card

## Strait of Hormuz 2026 — Maritime Trade & Risk Analytics

**Type:** Data Analytics + Data Science  
**Dataset:** Simulation-based vessel-level maritime crisis dataset  
**Records:** 1,890  
**Vessels:** 342

### Stack

Python | Pandas | NumPy | SciPy | Scikit-learn | XGBoost | SQL | Power BI

### Main outputs

- Trade-tier cost analysis
- Rerouting analysis
- Statistical hypothesis testing
- XGBoost classification
- Isolation Forest anomaly detection
- Operational risk metrics
- Power BI-ready datasets

### Main ML task

Predict the simulated `rerouted` outcome without using variables that directly reveal the outcome.

### Main analytical principle

**Describe what the supplied simulation shows; do not treat simulated relationships as verified real-world causality.**
